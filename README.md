# 🌱 CultivaSense 2.0
### Smart Agriculture Monitoring System

CultivaSense 2.0 is a Python Flask-based web application designed to support smart agriculture through a digital monitoring dashboard.

## 🚀 Features
- User registration and login
- Farmer dashboard
- Web-based interface
- Database integration
- Sensor monitoring dashboard (under development)

## 🛠️ Technologies Used
- Python
- Flask
- HTML
- CSS
- SQLite
- Git & GitHub

## 📂 Project Structure
- `app.py` — Main Flask application
- `database.py` — Database-related code
- `templates/` — HTML templates
- `static/` — Static website assets

## 🌡️ Future Improvements
- ESP32 sensor integration
- Real-time temperature and humidity monitoring
- Soil moisture monitoring
- Smart irrigation recommendations
- AI-powered agricultural insights
